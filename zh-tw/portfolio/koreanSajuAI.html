韓國四柱 AI 命理分析平台

  • 採用 Next.js / TypeScript 前端與 FastAPI 後端開發；具備無狀態架構（stateless），不持久化留存任何使用者資料。
  • 重構 Prompt 以符合快取條件（cache-eligibility），並將靜態規則庫替換為經 Python 預先計算的命盤專屬關聯，成功降低約 75% 的 LLM 生成成本（單次呼叫減少約 18% Token，且品質零損失）。
  • 導入基於 Redis 的限流機制（Rate Limiting）與防濫用保護。
  • 完成英／韓／繁中完整的在地化（Localization）支援與客製化設計系統（Design System）。
