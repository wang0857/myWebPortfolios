燕雲十六聲 AI 遊戲攻略助理

  • 以 React 19 + NestJS + OpenAI GPT-4o 打造全端 AI 搜尋助手，透過 SSE 實現逐字串流回應，模擬 ChatGPT 打字效果與即時「思考步驟」動畫。
  • 設計穩健的狀態管理機制，涵蓋載入、部分回應、錯誤狀態，並實作每日 Token 使用限制與快取策略，兼顧成本控管與 API 效能。
  • 導入 React.lazy 程式碼分割、API 請求防抖（debounce）與 React.memo 記憶化，提升應用效能與可擴展性。
  • 完成中英雙語（i18n）介面，具備自動語言偵測，並以模組化、可重用元件架構設計，利於後續功能擴充。
